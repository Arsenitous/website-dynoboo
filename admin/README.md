# DynoBoo Admin Dashboard

This is the internal Admin & Semi-POS Dashboard for DynoBoo. It manages product catalogs, stock, workshops, invoicing, and loyalty programs.

## Features

- **Dashboard Semi-POS**: Overview of store performance and transactions.
- **Invoice Management**: Create, edit, and track transactions.
- **Product & Workshop Catalog**: Master data for products and workshops, including stock tracking.
- **Loyalty Logbook**: Customer loyalty tracking.
- **Settings**: Shop profile and access control.

## Getting Started

First, install the dependencies if you haven't already:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Tech Stack

- Next.js
- React
- Supabase (Backend/Database)
- Custom CSS Variables for styling
